# License decision for Solum

**Chosen: Option A — Business Source License 1.1 (BUSL-1.1).**

Parameters and grant text are aligned with [Ferrum](https://github.com/SynapticFour/Ferrum) and [Ferrum Lab Kit](https://github.com/SynapticFour/Ferrum-Lab-Kit) (product name and repo URL adapted). See the root [LICENSE](../LICENSE).

## Why A

- Portfolio consistency with Ferrum / Lab Kit open-core posture.
- Clear commercial-licensing path for hosted or commercial deployments.
- Research / internal-research Additional Use Grant preserved; Change License Apache-2.0 after four years.

## Option B (not selected)

Pure Apache-2.0 from day one was considered for stronger OSI / clinical-tender optics. It remains a possible future Change License path (already the BUSL Change License) but is not the day-one license.

## Historical comparison (kept for context)

| | BUSL-1.1 (chosen) | Apache-2.0 (not chosen day-one) |
|---|---|---|
| Portfolio fit | Matches Ferrum / Lab Kit | Diverges; must be explained |
| Clinical tender optics | Source-available, not OSI | Stronger OSI signal |
| Commercial exclusivity | Stronger default | Weaker; monetize via support/hosting |
